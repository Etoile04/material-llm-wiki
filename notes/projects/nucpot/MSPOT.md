# NucPot MSPOT 战略 — 2026 Q2

## Mission (使命)

构建核材料原子间势函数的开放式验证平台，使研究人员能够自动化评估势函数质量，并通过多智能体系统持续积累可靠的参考物性数据。

## Strategy (策略)

1. **快慢线分离**: 快线秒级响应验证需求，慢线周级批量积累数据
2. **多智能体协作**: nucpot-db 编排 + nucpot-librarian 搜索提取 + researcher 审查
3. **三级缓存**: L1(PG) → L2(NFMD) → L3(llm-wiki+ontofuel)，逐级扩大覆盖
4. **开放集成**: 验证 API + NFMD 平台 + 势函数网站三位一体
